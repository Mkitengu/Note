# Smart Quick Notebook

Web notebook thông minh giúp ghi nhớ thông số với các nhãn văn bản cố định (chỉ sửa trong Cài đặt) và các ô nhập số liệu linh hoạt có thể xóa/chỉnh sửa tự do trên giao diện chính.

## ✨ Tính Năng Nổi Bật

- **Nhãn cố định (Fixed Labels)**: Khóa an toàn không lo bấm nhầm xóa mất chữ khi nhập liệu. Chỉ chỉnh sửa/thêm/bớt khi vào mục Cài đặt (⚙️).
- **Nhập & Xóa số liệu linh hoạt**: Nhập số, chỉnh sửa và xóa nhanh bằng 1 click hoặc xóa từng dòng với nút `✕`. Có hỗ trợ nút **Hoàn tác**.
- **Điều hướng bàn phím nhanh**:
  - `Enter` / `Tab` / `↓`: Nhảy sang dòng tiếp theo.
  - `Shift + Enter` / `↑`: Lùi về dòng trước.
- **Bộ danh mục (Templates) phong phú**: Tự tạo nhiều bộ thông số mẫu khác nhau (Kết cấu, Kích thước, Dự toán...).
- **Sao chép 1-Click (📋)**: Copy toàn bộ thông số và ghi chú để dán vào Excel, Word, CAD, Zalo...
- **4 Giao diện màu sắc (🎨)**: Tối (Sticky Dark), Xanh đêm (Midnight), Ấm áp (Amber Note), Sáng (Clean Light).
- **Tự động lưu trữ**: Lưu dữ liệu vào `localStorage`, hỗ trợ Xuất / Nhập file sao lưu JSON.

## 🚀 Cài Đặt & Sử Dụng

Mở trực tiếp tệp `index.html` trong bất kỳ trình duyệt web nào.
